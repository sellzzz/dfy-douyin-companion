# dfy-抖音陪看

**把桌宠拖到抖音视频上，调整绿色框并确认，它就在框里陪你看。**

Windows 上的本地 AI 桌宠原型。复用 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的桌宠、动画和气泡能力，用 Electron 采集选定窗口，再交给本机 Ollama 视觉模型生成简短回应。

> 早期原型，已在一台 Windows 11 / RTX 5070 电脑上跑通真实拖放、画面理解和气泡更新。尚无语音理解、长期记忆或连续视频推理。模型可能误认画面和人物，回应不代表视频事实。

## 怎么用

1. 双击桌面 **dfy-抖音陪看**，桌宠出现，控制面板默认隐藏。
2. 打开抖音 Windows 客户端，或在 Chrome/Edge 打开抖音、播放视频。
3. 把桌宠拖到视频画面中间，松手后出现绿色选框。
4. 拖动框体移动范围，拖动边角调整大小；也可点“重新画框”。只框住希望宠物看的视频内容，再点 **确认陪看**。
5. 确认后绿色框自动隐藏。宠物沿用原桌宠的待机、小动作、转身和走路动画，在选定范围内活动；取景范围不随宠物移动。

- 头上的 **Ⅱ**：暂停 / 继续分析。
- 选框里的 **取消**：结束本次采集；重新拖放桌宠可再次选框。
- 拖到抖音窗口以外：停止采集。
- 头上的 **×**：通知陪看停止，然后关闭桌宠。
- 系统托盘：暂停、结束陪看、备用控制面板、退出。

支持抖音 Windows 客户端和 Chrome/Edge 中的抖音，普通 Chrome 独立配置也可以使用，无需复制 Cookie、安装浏览器扩展或开启浏览器调试端口。客户端按所属 `douyin.exe` 进程识别，即使窗口标题显示为 `douyin` 或视频标题也能选择；浏览器仍须为 Chrome/Edge 且标题包含“抖音”。手机和其他平台尚未适配。

## 安装

需要 **Windows 10/11 x64、Node.js ≥22.12、PowerShell 7、抖音客户端或 Chrome/Edge、Ollama**。建议使用 Node.js 24。先从官方安装 [Node.js](https://nodejs.org/)、[PowerShell](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows) 和 [Ollama](https://ollama.com/download/windows)，安装后重新打开终端。

```powershell
git clone https://github.com/sellzzz/dfy-douyin-companion.git
cd dfy-douyin-companion
pwsh -NoProfile -File .\scripts\setup.ps1
```

安装脚本会安装锁定的项目依赖、`dsh-pet@0.3.8`，准备其 Electron 运行时，并拉取 `qwen3-vl:2b-instruct-q4_K_M` 本地视觉模型（约 2 GB 下载）。模型已存在时复用。脚本随后创建桌面快捷方式。安装过程中不需要抖音密码或账号令牌；抖音登录和验证码由你在自己的浏览器中完成。

也可以手动启动：

```powershell
pwsh -NoProfile -File .\scripts\start-doupet.ps1
```

首次使用模型的加载时间比热启动长。实测过的约 0.4 秒是单次模型处理时间，采样周期目前为 5 秒，不等于完整响应延迟，也不保证其他机器相同速度。

## 工作原理

```text
拖动桌宠并松手
  → 判断鼠标下最上层的窗口是否是抖音客户端或抖音浏览器窗口
  → 仅采集这个窗口
  → 本地模型识别视频区域；失败时围绕拖放点取景
  → 显示可调整的绿色框，等待本人确认
  → 隐藏选框；宠物按范围缩小（需要时），按原有动画节奏活动
  → 约每 5 秒读取一帧
  → Ollama / Qwen3-VL 生成一句感想
  → dsh-pet 气泡显示
```

松手后不会把桌宠甩飞；拖到别处可结束陪看。自动边框定位尚不稳定，务必检查绿色框后再确认；确认前不会生成陪看感想。为定位初始边框，本地模型仍会先读取一次所选窗口画面。备用面板仍保留手动选窗、框选方式。

确认后的范围会在后台跟随所选窗口移动、缩放，相对位置保持不变；绿色框只在选择时显示。播放器布局发生变化时请重新拖放选框。窗口最小化、离开抖音、暂停或结束采集时停止漫游。画面连续静止约 8–10 秒也会暂歇，有变化后恢复，这是画面变化判断，不能精确识别视频的播放按钮状态。

移动沿用 dsh-pet 的随机动作链和由动画播放时间驱动的走路：动作起步和收尾会停顿，碰到边界时通过转身动画换向。不会另行把待机中的宠物拉到随机位置；文字气泡也不会通过占用锁反复打断走路。窄框中可用空间少时会缩短步幅或留在原地做小动作。

## 数据与权限

- 视觉推理使用 `127.0.0.1:11434` 上的本机 Ollama；当前实现没有云端模型调用。
- 不自动点赞、评论、发私信、发布视频或操作抖音账号；不读取 Cookie 或浏览器密码数据库。
- 原始截图只在内存中处理，不写入磁盘；本机 `work/` 保存依赖、配置、运行日志和最近一次文字回应。
- 暂停会停止模型分析，但备用面板中的本地预览仍可继续；“结束采集”停止视频流。
- 本机桌宠服务使用端口 3081，拖放控制通道使用 3082，均限回环地址；3082 的随机进程凭据只保存在本机运行目录。
- 窗口所属程序、浏览器标题检查和模型的登录界面识别并非完整隐私防护。输入账号、验证码或其他敏感内容前，请结束采集。

`work/`、模型、浏览器数据、运行凭据、截图、个人配置和日志均不进入 Git。项目没有设置开机自启。

## 开发与验证

```powershell
npm ci
npm test
npm run check
```

`tests/` 检查选框坐标与预览黑边转换、完整宠物的活动边界、确认/取消/暂停/窗口变化的状态，以及安装补丁的可重复应用。运行时采用 npm 锁定的 `dsh-pet@0.3.8`；上游升级后必须重新检查补丁锚点和兼容性，不应直接替换为 latest。

本仓库发布的是当前“原生窗口采集 + 本地视觉模型”链路。早期 DSH 插件和抖音元数据读取实验不包含在运行依赖中。
